# Gmail Signature Setup

## Step 1: Edit the Template

1. Open `cattlytx-signature-template.html` in TextEdit or Notepad
2. Replace with your info:
   - `Your Full Name`
   - `Your Job Title`
   - `your.email@cattlytx.com` (appears twice)
3. For phone number:
   - **Don't want one?** Delete the 3 phone lines
   - **Want one?** Replace `Your-Phone-Number` (appears twice) and delete the comment lines
4. Save as `my-signature.html`

## Step 2: Add to Gmail

1. Open `my-signature.html` in your **web browser**
2. Select everything and copy it
3. Go to Gmail → Settings ⚙️ → "See all settings"
4. Scroll to "Signature" section → "+ Create new"
5. Paste into the text box
6. Save changes

**Important:** Copy from the browser, not from TextEdit/Notepad, or it will paste as code.
